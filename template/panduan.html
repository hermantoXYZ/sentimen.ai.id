Panduan Penggunaan Sentimen.ai.id
Sentimen.ai.id adalah platform analisis sentimen berbasis NLP yang berfokus pada ekosistem ekonomi digital Indonesia — mencakup ulasan produk UMKM, komentar pelanggan di media sosial, percakapan pasar digital, serta opini publik terhadap bisnis online. Semua hasil analisis tersimpan otomatis ke database lokal (instance/social_monitor.db) dan langsung memperbarui grafik serta statistik di seluruh halaman.
1. Alur Kerja — Analisis Sentimen Bisnis Digital
  1. Masukkan Data melalui Analisis Teks Cepat di Home, Upload CSV (data ulasan/komentar pelanggan), atau salah satu analyzer media sosial (YouTube, Threads, TikTok, Twitter/X, Instagram).
  2. Pilih Model NLP yang sesuai untuk mengklasifikasikan sentimen menjadi positive, negative, atau neutral beserta skor confidence (%).
  3. Lihat Visualisasi & Insight di menu [Analysis] — distribusi sentimen, tren 7 hari, WordCloud kata kunci bisnis, evaluasi model (Precision/Recall/F1), serta tabel Top Engaging Posts — atau pantau secara realtime di [Live!].
Contoh penggunaan: UMKM dapat menganalisis ratusan ulasan Tokopedia/Shopee yang diekspor ke CSV, pemilik brand dapat memantau sentimen komentar TikTok Shop, atau analis dapat membandingkan persepsi publik terhadap produk lokal vs impor dari data Twitter/X.
2. Pilihan Engine / Model NLP (Model, Formula & Referensi)
  • 1) NLTK / TextBlob (Lexicon-Based + Negation Shifting) FAST
    Analisis cepat berbasis kamus kata positif/negatif Bahasa Indonesia & Inggris (POS_ID, NEG_ID), dilengkapi deteksi kata negasi (tidak, bukan, kurang, gak, belum) serta polaritas TextBlob.
    Persamaan Matematis:
    $$S(d) = \sum_{i=1}^{n} \delta(w_{i-1}) \cdot \text{pol}(w_i)$$
    di mana fungsi pembalik negasi $\delta(w_{i-1})$ dan fungsi aturan klasifikasi akhir didefinisikan sebagai:
    $$\delta(w_{i-1}) = \begin{cases} -1, & \text{jika } w_{i-1} \in \mathcal{N} \text{ (kata negasi)} \\ +1, & \text{lainnya} \end{cases}$$ $$\hat{y} = \begin{cases} \text{Positive}, & \text{jika } S(d) > 0 \text{ atau } (S(d) = 0 \land p > 0.1) \\ \text{Negative}, & \text{jika } S(d) < 0 \text{ atau } (S(d) = 0 \land p < -0.1) \\ \text{Neutral}, & \text{jika } S(d) = 0 \land -0.1 \le p \le 0.1 \end{cases}$$
    dengan $p \in [-1.0, +1.0]$ merupakan skor polaritas kontinyu dari TextBlob.
    Referensi: Bird et al. (2009), Natural Language Processing with Python (NLTK); Loria (2018), TextBlob: Simplified Text Processing; Liu (2012), Sentiment Analysis and Opinion Mining (Lexicon & Negation Shifting).
  • 2) scikit-learn (TfidfVectorizer + MultinomialNB) ML
    Model klasifikasi Multinomial Naive Bayes dengan pembobotan fitur TF-IDF n-gram (1, 2) dan Laplace/Lidstone smoothing ($\alpha = 0.5$) yang dilatih pada korpus kalimat Indonesia & Inggris.
    Persamaan Matematis:
    $$\text{TF-IDF}(t, d) = \text{tf}(t, d) \times \left[ \ln\left(\frac{1 + N}{1 + \text{df}(t)}\right) + 1 \right]$$ $$\hat{y} = \arg\max_{c \in \mathcal{C}} \left[ \ln P(c) + \sum_{i=1}^{|V|} x_i \ln P(t_i \mid c) \right]$$
    dengan estimasi probabilitas bersyarat menggunakan Lidstone smoothing:
    $$P(t_i \mid c) = \frac{N_{c,i} + \alpha}{N_c + \alpha |V|}$$
    di mana $N$ adalah jumlah total dokumen, $\text{df}(t)$ adalah frekuensi dokumen term $t$, $x_i$ adalah bobot TF-IDF fitur ke-$i$, dan $|V|$ adalah ukuran kosakata (vocabulary).
    Referensi: Pedregosa et al. (2011), Scikit-learn: Machine Learning in Python, JMLR 12; McCallum & Nigam (1998), A Comparison of Event Models for Naive Bayes Text Classification, AAAI-98; Manning et al. (2008), Introduction to Information Retrieval (TF-IDF & Naive Bayes).
  • 3) Transformers (IndoBERT — mdhugol/indonesia-bert-sentiment-classification) DEEP
    Model Deep Learning berbasis arsitektur Transformer dua arah (BERT) yang di-fine-tune khusus untuk klasifikasi sentimen Bahasa Indonesia (maksimal 512 token). Otomatis beralih ke scikit-learn jika library transformers belum terpasang.
    Persamaan Matematis:
    $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V$$ $$P(y = c \mid \mathbf{h}_{[\text{CLS}]}) = \frac{\exp(\mathbf{w}_c^\top \mathbf{h}_{[\text{CLS}]} + b_c)}{\sum_{k \in \mathcal{C}} \exp(\mathbf{w}_k^\top \mathbf{h}_{[\text{CLS}]} + b_k)}$$ $$\hat{y} = \arg\max_{c \in \mathcal{C}} P(y = c \mid \mathbf{h}_{[\text{CLS}]})$$
    di mana $Q, K, V$ adalah matriks Query, Key, Value berdimensi $d_k$, dan $\mathbf{h}_{[\text{CLS}]} \in \mathbb{R}^{768}$ adalah vektor representasi agregat dari token klasifikasi [CLS] pada lapisan akhir encoder.
    Referensi: Devlin et al. (2019), BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding, NAACL-HLT; Wilie et al. (2020), IndoNLU: Benchmark and Resources for Evaluating Indonesian NLU (IndoBERT), AACL-IJCNLP; Vaswani et al. (2017), Attention Is All You Need, NeurIPS.
3. Panduan Fitur & Halaman
A. Home / Dashboard (/)
  • Indeks Sentimen Bisnis Digital: Menampilkan skor sentimen keseluruhan (0–100%) serta jumlah post Total, Positive, Negative, dan Neutral dari seluruh data yang dianalisis.
  • Analisis Teks Cepat: Langsung ketik ulasan produk, komentar pelanggan, atau opini terkait UMKM/bisnis, pilih model NLP, lalu klik Analisis & Simpan.
  • Reset Data: Klik tombol Reset Data di bar Riwayat Analisis Terbaru untuk menghapus seluruh data lama dan memulai dari awal.
B. Upload Dataset CSV (/upload)
  • Kolom wajib pada file CSV: platform, username, text.
  • Kolom opsional: created_at, likes, shares. Ukuran maksimal file 16 MB.
  • Contoh penggunaan: ekspor ulasan Tokopedia/Shopee ke CSV, lalu upload untuk analisis sentimen massal.
  • Gunakan tombol Sample CSV untuk mengunduh contoh format CSV yang benar.
C. Visualisasi Sentimen & Tren (/analyze)
  • Filter berdasarkan platform melalui dropdown di kanan atas (All Platforms atau per platform).
  • Menampilkan grafik Sentiment Distribution, Platform Share, 7-Day Trend, WordCloud Kata Kunci Bisnis, tabel Evaluasi Model (Precision/Recall/F1), serta Top Engaging Posts.
  • Precision/Recall/F1-Score: Metrik evaluasi model berbasis self-confidence (threshold ≥60%) — menggambarkan seberapa yakin model terhadap klasifikasi sentimen data bisnis Anda.
D. YouTube Analyzer (/youtube-analyzer)
  • URL Video Review: Tempel URL video review produk UMKM, unboxing, atau tutorial bisnis untuk menganalisis sentimen komentar.
  • Channel Bisnis: Masukkan @handle atau Channel ID (UC...) untuk memetakan sentimen seluruh video channel.
E. Threads, TikTok, Twitter/X, & Instagram Analyzer
  • Threads (/threads-analyzer): Analisis percakapan bisnis & opini konsumen dari URL post/profil threads.net.
  • TikTok (/tiktok-analyzer): Analisis komentar & caption video promosi produk TikTok Shop dari URL video atau @username.
  • Twitter/X (/twitter-analyzer): Pantau buzz & sentimen publik terkait brand/produk dari URL tweet atau @username.
  • Instagram (/instagram-analyzer): Analisis caption & komentar postingan promosi bisnis. Jika akses publik dibatasi login, gunakan form Paste Komentar / Caption IG.
F. Live Monitor (/live-monitor)
  • Memantau 15 data terbaru secara otomatis setiap 5 detik via /api/live-feed.
  • Menampilkan Live Gauge Chart serta peringatan otomatis apabila rasio sentimen negatif melebihi 25% — berguna untuk crisis monitoring brand bisnis.
4. Konfigurasi API Opsional (File .env)

Aplikasi dapat berjalan tanpa API key untuk mode publik/input manual. Untuk hasil lebih lengkap pada masing-masing platform (berguna untuk riset pasar UMKM secara mendalam), tambahkan token berikut di file .env lalu restart server:

YOUTUBE_API_KEY=isi_api_key_youtube
THREADS_ACCESS_TOKEN=isi_token_threads
TWITTER_BEARER_TOKEN=isi_bearer_token_x
INSTAGRAM_ACCESS_TOKEN=isi_token_instagram
Tips untuk UMKM: Gunakan Upload CSV untuk analisis massal tanpa API key — ekspor ulasan dari marketplace (Tokopedia, Shopee, Lazada) ke format CSV, lalu upload langsung ke sistem.
